# Step 3 - Specify

Complete `requirements-and-verification-matrix.md`. Every requirement must be uniquely identified, measurable, and linked to a verification method.

## Review gate

- Functional and quality requirements are both included.
- Requirements state what must be achieved, not how to implement it.
- Targets and tolerances are measurable.
- Every requirement has a feasible verification method.
- Safety, sustainability, ethical implications, and responsible AI use have been considered where relevant.
