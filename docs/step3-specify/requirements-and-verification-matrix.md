# Requirements and Verification Matrix

## Requirement-writing convention

Use: `The system shall [observable behavior] [under stated condition] [with measurable target].`

| ID | Category | Requirement | Priority | Verification method | Planned evidence | Status |
|---|---|---|---|---|---|---|
| FR-01 | Functional | `[The system shall...]` | Must | Test | `[Record/data]` | Planned |
| PR-01 | Performance | `[Measurable target]` | Must | Test | `[Record/data]` | Planned |
| SF-01 | Safety | `[Safe behavior]` | Must | Demonstration | `[Video/log]` | Planned |
| SU-01 | Sustainability | `[Energy/material objective]` | Should | Analysis | `[Calculation]` | Planned |
