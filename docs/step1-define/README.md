# Step 1 - Define

Complete `project-charter.md`, then submit a pull request titled `Step 1: Define - [Project short name]`.

## Review gate

- The problem and intended outcome are clear.
- The baseline system and proposed extension are distinguished.
- A focused, answerable research question is stated.
- Scope, stakeholders, constraints, risks, and exclusions are identified.
- Success criteria are measurable and feasible within the semester.
