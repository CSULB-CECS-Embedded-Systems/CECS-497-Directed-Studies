## Purpose

This repository documents a CECS 497 undergraduate directed-research project through a six-step research and development workflow. The objective is not only to produce a working prototype, but also to define a research question, justify engineering decisions, collect evidence, and communicate what was learned.

## Six-step workflow

1. **Define** - establish the problem, research question, scope, stakeholders, constraints, and success criteria.
2. **Investigate** - examine prior work, the baseline system, technologies, risks, and knowledge gaps.
3. **Specify** - write measurable requirements and define how each requirement will be verified.
4. **Design** - develop and justify the hardware, software, communication, and experimental designs.
5. **Implement and Verify** - build incrementally, test subsystems, integrate the system, and retain reproducible evidence.
6. **Evaluate and Communicate** - analyze results, answer the research question, discuss limitations, and present the work.

Each step ends with an instructor review gate. Iteration is expected: evidence discovered later may require a documented revision to an earlier artifact.

## Working expectations

- Create a feature branch for each substantial change.
- Connect work to an issue describing the goal and acceptance criteria.
- Submit a pull request for each workflow gate and for major implementation features.
- Update `docs/weekly-progress/` before every meeting.
- Record important decisions in `docs/meeting-records/`.
- Store test procedures in `tests/` and resulting data in `results/`.
- Do not place passwords, access tokens, private credentials, or sensitive personal data in this repository.

## Repository map

- `docs/step1-define/` through `docs/step6-evaluate-communicate/`: workflow artifacts
- `docs/weekly-progress/`: weekly updates
- `docs/meeting-records/`: decisions and action items
- `hardware/`: schematics, wiring, component information, mechanical designs, and bills of materials
- `software/`: source code and build instructions
- `tests/`: test procedures, scripts, and verification records
- `results/`: processed data, tables, charts, and analysis
- `media/`: selected project images and links to demonstrations

## Final deliverables

- Complete repository with source files and research records
- Working prototype or documented experimental outcome
- Requirements and verification evidence
- Final technical report
- Presentation and demonstration
- Individual reflection on results, limitations, and future work
